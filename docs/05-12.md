## 3. Prompt 装配评审

### ✅ 整体观感良好

- 七层 markdown 标题清晰：`# Persona` / `# Developer rules` / `# Environment
  context` / `# Long-term memory (cross-session)` / `# User project
  instructions` / `# Available skills` / `# Conversation summary so far`
- 层间空行分隔（`sections.join("\n\n")`），跟 codex 同样风格
- `<environment_context>` XML 子结构稳定（cwd / shell / current_date / timezone）
- `<INSTRUCTIONS>` 包住 AGENTS.md 内容，边界清晰
- Long-term memory 在 user project instructions **之前**——cross-session →
  per-project 的从泛到精顺序合理

### ⚠️ 小问题（可改可不改）

**(A) AGENTS.md heading 在根目录时冗余**

`session-primer.ts:238`：
```ts
const header = `# AGENTS.md instructions for ${displayPath || path.basename(absolutePath)}`;
```

当 `AGENTS.md` 在 workspace 根（displayPath = `"AGENTS.md"`），实际输出：
```
# AGENTS.md instructions for AGENTS.md
```

不影响模型理解，但是个尴尬的"AGENTS.md for AGENTS.md"。
最小改动：

```ts
const header = displayPath === "AGENTS.md"
  ? "# AGENTS.md instructions"
  : `# AGENTS.md instructions (${displayPath})`;
```

**(B) Skills 段 intro 把"故意的空行"过滤掉了**

`lib/chat-agent/system-prompt.ts:110-121`：

```ts
const intro = [
  "Use the `skill` tool to load any of the skills listed below...",
  "",                           // 故意放的空行
  "When to invoke:",
  ...
]
  .filter((line) => line.length > 0)  // ← 把那空行也滤掉了
  .join("\n");
```

输出：
```
Use the `skill` tool ... extends what you can do in this conversation.
When to invoke:
- ...
```

intro 段落和 "When to invoke:" 列表挤在一起。对比 memory 段（`system-prompt.ts:71-79`）没用 filter，空行得以保留——读起来更清爽。

修复：filter 只过滤 `userInvocableHint` / `modelGatedHint` 这俩条件 line，不要过滤显式空字符串。

**(C) 没有 layer 边界保护**

每层用 `# Heading` 分隔。如果 developer rules 里某条规则正好以 `# Something` 开头（比如某天加一条规则说"使用 markdown 标题 # Section"），模型可能误解层边界。

低概率风险，当前所有 layer 内容都用 `##` 起步规避了；保留这个观察供未来加新层时注意。

## 4. Memory 内容评审

### 实测产出（gpt-5.5 跑一轮 7 turn）

**`raw_memories.md`**（Phase 1 抽取，按时间追加）：
```markdown
- [user] [global] User is a senior TypeScript engineer with 8 years of experience.
- [user] [global] Prefers concise, direct answers without lengthy explanations.
- [project] [/Users/apple/Desktop/project/ai-sdk-demo] User is learning Vercel AI SDK v6 in this repo, aiming to build their own agent dev flow.
```

**`MEMORY.md`**（Phase 2 整合）：
```markdown
# Memory index

_Last consolidated: 2026-05-12_

## Global (all projects)
- [user] Senior TypeScript engineer with 8 years of experience
- [user] Prefers concise, direct answers without lengthy explanations

## Project: /Users/apple/Desktop/project/ai-sdk-demo
- [project] Learning Vercel AI SDK v6 to build their own agent dev flow
```

**`rollout_summaries/<thread>-ai-sdk-demo-user-profile-preferences.md`**：
```
用户说明自己是 senior TypeScript 工程师，在 ai-sdk-demo 学习 Vercel AI SDK
v6，目标是形成自己的 agent dev flow；偏好简洁直接回答且不要冗长解释。
```

### ✅ 高质量信号

1. **Scope tag 准确**：身份 / 偏好 → `[global]`；项目目标 → `[project] [<path>]`。
   没把项目特定细节误标全局。
2. **Phase 1 → Phase 2 缩写适度**：raw_memories 是完整事实句，MEMORY.md
   index 砍成 ≤200 char bullet，跟 `consolidator-prompt.ts:29` 的约束一致。
3. **Slug 命名 reasonable**：`ai-sdk-demo-user-profile-preferences` 一眼能
   看出这条 rollout 的主题。
4. **Header metadata 全**：每条 raw_memories 带 `thread_id` /
   `workspace_root` / `recorded_at` 注释，方便日后审计追溯。
5. **中英混合自然**：rollout summary 用中文（user 输入是中文 prompt），
   raw_memories / MEMORY.md 用英文（更紧凑、token 友好）——这是 prompt
   设计有意为之，效果到位。

### ⚠️ 观察项（不是 bug，是后续 dogfood 要看的）

1. **重复抽取风险**：raw_memories.md 是 append-only。如果用户在多个 session
   反复说"我喜欢简洁回答"，会重复抽好几次。Phase 2 整合时 dedup（看
   `MEMORY.md` 输出确实只剩一条），但 raw_memories.md 本身会膨胀。
   →  现状可接受；如果跑一个月发现 raw_memories 涨到 MB 级，再加一道
   `dedupBy=fact-text` 的截断。
2. **Project tag 用绝对路径**：`[project] [/Users/apple/Desktop/project/ai-sdk-demo]`
   ——换机器 / 换路径就匹配不上了。短期 OK，长期可以考虑 `project-id` 而不
   是 path（但要额外注册）。
3. **没看到"过往决定 / 项目背景"类记忆**：测试 prompt 主要给的是身份 + 偏好
   + 项目目标。没测到"我们决定用 X 而不是 Y"这种**决策**类抽取。下次跑一段
   多轮含技术决策的对话再 review 一次。

### 跨对话注入验证

A1 注入路径：`buildSystemPrompt({globalMemory})` → `# Long-term memory
(cross-session)` 段（见 snapshot test 第 4 个 case）。intro 包含 5 条 usage
guidance，写得清楚：
- treat as authoritative
- don't mention you're reading memory
- 当前 turn 与 memory 冲突时信当前
- 找不到对应记忆是正常

这一段质量在线，是 codex 风格 + 适度本地化的好例子。
